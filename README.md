# 魔法角度冒險王國 - 國小四年級互動數學樂園 (math4-03)

專為國小四年級數學「角度」單元設計的魔法主題互動學習網站。

## 功能特色

1. **量角器大解密**：互動式半圓量角器，動態切換內外圈刻度、對齊中心與零刻度線練習量角。
2. **畫角魔法杖**：拖曳角度刻度指針，動態繪製指定角。
3. **角的世界分類**：趣味卡牌互動分類銳角、直角、鈍角、平角與周角。
4. **時鐘轉動與角度**：指針旋轉夾角計算，理解順時針與逆時針旋轉角。
5. **三角板與內角計算**：常用三角板（45°-45°-90°、30°-60°-90°）角度組合拼角與內角和演算。
6. **王國試煉測驗**：即時回饋、紙花慶祝特效與詳細解析。
7. **懸浮草稿計算紙**：隨點隨開的草稿板，方便學童手寫演算。
8. **16:9 劇院模式**：自適應大螢幕與電子白板教學。
